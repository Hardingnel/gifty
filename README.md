# University Life Management Survey: Complete Web & Desktop Data Pipeline

**Research Topic**: *Assessing the Need for a University Life Management Foundation Course: Exploring Students’ Experiences, Challenges and Support Needs*

An end-to-end data pipeline and research suite connecting **Google Forms** responses to:
1. **Next.js Web KPI Dashboard** (Deployable to **Vercel** with real-time Google Sheets sync and browser-based Clean Excel export)
2. **Automated Excel Dashboard Workbook** (5-tab executive `.xlsx` generated by Python)
3. **Streamlit Local Web App** (Alternative lightweight Python UI)
4. **Google Form 10-Second Auto-Creator** (Google Apps Script that builds all 9 sections and 27 questions automatically)

## 🌐 Features of the Web Dashboard

- **Live Google Sheets Ingestion**: Connect any live Google Sheet URL directly in the top bar.
- **Dynamic Demographic Filters**: Filter results on the fly by *Level of Study*, *Institution Type*, and *Gender*.
- **Interactive Visualizations (Recharts)**:
  - Central Research Question Donut Chart (Q24: Foundation Course Utility)
  - Priority Guidance Demands Ranked Bar Chart (Q23)
  - Institutional Support Deficit Matrix Across 5 Pillars
  - Preferred Learning Formats Bar Chart (Q25)
  - Cross-Tabulation Grouped Bar Chart by Academic Level (Q18 & Q22)
  - Non-Academic Demands Managed Bar Chart (Q1)
- **1-Click Clean Excel Download**: Click *"Download Clean Excel (.xlsx)"* anytime to download the complete 5-tab formatted Excel workbook directly in your browser.
- **Qualitative Quotes Explorer**: Search and filter open-ended answers to Q26 and Q27 by keyword, degree programme, or year of study.
